# Eclipse e(fx)clipse™

Welcome to the official repository for **Eclipse e(fx)clipse™**. This project provides JavaFX integration for the Eclipse platform, alongside runtime frameworks designed for building modern, high-performance rich-client applications using JavaFX.

## 🚀 Key Components

This project encompasses several core components to support JavaFX development:

* **efxclipse-rt**: The core runtime libraries and application frameworks for JavaFX.
* **efxclipse-eclipse**: Tooling and integration plugins directly built for the Eclipse IDE (wizards, editors, and launchers).
* **efxclipse-drift**: A high-performance C++ library tailored for direct integration with native graphics renderers.

## 🛠️ Prerequisites

To build or work with the e(fx)clipse source code, you generally need:
- **Java Development Kit (JDK)** (matching the required target JavaFX version)
- **Eclipse IDE** (preferably the "Eclipse IDE for Enterprise Java and Web Developers")
